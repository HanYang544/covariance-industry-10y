# 实验协议

[返回首页](../README.md) · [方法讲解导航](methods/README.md) · [损失公式与早停解释](methods/training.md)

训练2008–2017、验证2018–2020、测试2021–2025，样本2498/736/1235。2003–2007用于历史预热，不属于监督标签。

标签为t+1到t+20的中心化样本协方差，分母19；不允许标签跨越划分边界。100个历史20日矩阵覆盖119个收益日，不是2000个不重叠交易日。

风险输入为100×6，训练集标准化后截断[-3,3]；矩阵输入为100×10×10，按训练历史矩阵元素标准化，不截断。

普通序列模型：Adam默认0.01、float64、128微批累积全训练集梯度、每轮一次更新、最多500轮、早停30、min_delta=1e-12、包含epoch0。学习率搜索只改变学习率。

CAB：Adam1e-4、批128内微批16、最多100轮、早停30、不含epoch0，骨干float32与矩阵float64。它不是严格相同训练配方下的编码器替换。

种子20261012/13/14；两种损失独立训练与验证选模。Frobenius为完整矩阵范数，Euclidean为含对角线上三角L2距离；均先逐样本计算再平均，不平方。

结果为种子均值（样本标准差），不是置信区间，也不是平均预测后再打分。重叠标签、重复测试查看和复用检查点都限制结论。

新训练器每轮同时记录完整训练集和验证集eval损失；CAB旧日志的train是更新过程中的批次汇总，不能不加说明直接混画。原未记录训练损失的实验不补造曲线。
