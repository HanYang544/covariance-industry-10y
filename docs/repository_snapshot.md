# GitHub项目快照说明

本仓库保存代码、配置、中文方法说明、原始数据和实验结果记录。模型权重（`.pt`）、二进制输入与预测缓存（`.npz`）、日志和Python缓存不上传，仍保留在原电脑；因此克隆仓库不等于取得全部已训练检查点，依赖这些文件的验证或复跑需要重新生成对应数据或从原电脑补齐。

原项目的`data/`及`outputs/`部分目录是Windows目录链接。实际数据和历史结果保存在`modules/fusion/`，只提交实际文件，避免重复上传。Windows克隆后可运行`./scripts/create_layout_links.ps1`恢复这些入口。

上传时已有后台实验可能继续运行；本次提交是当时的文件快照，不表示尚在进行的实验全部完成。预测结果以各文档列明的完成状态为准。
